# Interactive Web Experience

A React and Vite built Fortune telling interactive web experience. Ask questions and choose a flower to reveal your fortune. 

## Project structure

- `index.html` is the browser document and contains the `#root` element.
- `src/main.jsx` starts React and renders the `App` component into `#root`.
- `src/App.jsx` is the main component to edit when building the page.
- `src/index.css` contains global styles.
- `vite.config.js` and `eslint.config.js` contain development tooling configuration.
- `package.json` contains the scripts and dependencies. `package-lock.json` records exact dependency versions.
